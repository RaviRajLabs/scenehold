# SceneHold

SceneHold is a free Chrome extension that gives you more control over YouTube ad breaks and background playback.

**Website:** [ravirajlabs.github.io/scenehold](https://ravirajlabs.github.io/scenehold/)  
**Privacy Policy:** [Read the policy](https://ravirajlabs.github.io/scenehold/#privacy)  
**Support:** [Support SceneHold](https://dodo.pe/scenehold)

## Features

- Listening and Watching playback modes.
- Background playback choices in Watching mode: continue, pause while inactive, or resume when you return.
- Automatic use of YouTube skip and close controls when available.
- Optional ad muting with audio restoration that respects manual changes.
- Continue, Pause, or Smart actions after an ad, with optional resumption of SceneHold-created post-ad pauses.
- A local 10-action support milestone, enabled by default. Its capped count stays in Chrome, can be reset, and is deleted when disabled.
- Quick popup controls and a toolbar indicator for SceneHold’s active state.

## Platform support

SceneHold currently supports desktop YouTube in Chrome. Other streaming platforms are not supported yet.
